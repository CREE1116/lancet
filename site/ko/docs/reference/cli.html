전체 CLI & lancet rg 호환성 레퍼런스

전체 하위 명령 구문, 종료 코드, ripgrep 호환성 매트릭스.

모든 하위 명령은 .gitignore / .ignore / .rgignore 순회 규칙, 결정적 정렬, 구조화된 종료 코드를 공유합니다.

종료 코드#

코드의미상태 값 (JSON status)
0성공 / 결과 있음complete
1결과 없음 (또는 status에서 인덱스 없음)empty
2잘못된 쿼리·인자, 미지원 동작, 수정 충돌, I/O 오류invalid_query, unsupported, conflict

전체 하위 명령 & 플래그#

CLI 전체 목록
lancet <QUERY> [PATH] [--json] [--no-index | --trust-index] [--index-dir DIR] [--ocr]
                      [--hidden] [--no-ignore] [-j THREADS] [--max-lines N] [--max-cols N] [--stats]

lancet rg [FLAGS] [PATTERN] [PATH...] [--docs] [--passthru] [--type-add TYPESPEC]
                      [--no-index | --trust-index] [--index-dir DIR]

lancet fd [PATTERN] [PATH] [-p PATTERN] [-t f|d] [-e EXT] [--type-class CLASS] [-g | -r] [-s]
                           [-d DEPTH] [--changed-within DUR] [--min-size S] [--max-size S]
                           [--tree] [--dirs] [--limit N] [--meta]
                           [--no-index | --trust-index] [--index-dir DIR] [--json] [--stats]

lancet ast <PATTERN> [PATH] [-l LANG] [-r TEMPLATE [--apply]] [--path GLOB] [--limit N]
                            [--no-index | --trust-index] [--index-dir DIR] [--json] [--stats]

lancet read <TARGET> [-l START:END] [-s SYMBOL] [-p PAGE] [--sheet S] [--rows R] [--cols C]
                     [-e ENTRY] [--budget-tokens N] [--raw] [--ocr] [--json]

lancet outline [PATH] [-d DEPTH] [-e EXT] [--limit N] [--hidden] [--no-ignore] [--ocr] [--json]

lancet refs <SYMBOL> [PATH] [--rank [--kind KIND,...]] [-l LANG] [-e EXT] [--path GLOB]
                            [--all-files] [--limit N] [--no-index | --trust-index] [--json] [--stats]

lancet edit <PATH> (--lines RANGE | --symbol SYM | --find TEXT [--all] | --edits FILE)
                   (--with TEXT | --with-file FILE | --delete | --insert-before TEXT | --insert-after TEXT)
                   [--rev REV] [--apply] [--allow-syntax-errors] [--json]

lancet patch [DIFF|-] [--root DIR] [-p N] [--apply] [--allow-syntax-errors] [--json]

lancet rename <FILE:LINE[:COL]> <OLD> <NEW> [--rev REV] [--apply] [--json]

lancet mcp [--root DIR] [--read-only] [--trust-index] [-j THREADS]

lancet index [PATH] [--rebuild | --compact] [--index-dir DIR] [--ocr] [--hidden] [--no-ignore] [-j THREADS]
lancet status [PATH] [--index-dir DIR]
lancet parse <QUERY>
lancet explain <QUERY> [PATH] [--index-dir DIR] [--no-index | --trust-index] [--hidden] [--no-ignore]
lancet batch [PATH] (-q <QUERY>... [--name <NAME>...] | --queries-json <JSON>)
                    [--no-index | --trust-index] [--index-dir DIR] [--ocr] [--json]

lancet rg — ripgrep 호환성 표#

bench/rg_parity.py의 68개 엣지 케이스 픽스처와 Linux 커널 전체 쿼리를 ripgrep 15.2와 바이트 단위로 대조했습니다.

패턴 & 매칭#

플래그의미상태비고
-e, --regexp <PAT>검색 패턴 (중복 지정 가능)지원선택(alternation)으로 결합
-f, --file <FILE>파일에서 줄당 하나씩 패턴 읽기 (- stdin)지원
-F, --fixed-strings리터럴 문자열로 취급지원
-i / -s / -S대소문자 무시 / 구분 / 스마트지원마지막 플래그 우선; AST 기반 -S(\W 등은 무시 유지)
-w / -x / -v단어 경계 / 줄 전체 / 반전 매치지원rg 단어 경계 규칙과 동일
-U, --multiline-dotall여러 줄 매치 및 .에 개행 허용지원
-P, --pcre2PCRE2 전후방 탐색·역참조미지원선형 시간과 건전한 트라이그램 컴파일 보장을 위해 Rust regex만 사용

출력 & 형식#

플래그의미상태비고
-o, -c, --count-matches매치 부분만 / 매치 줄 수 / 총 매치 수지원
-l, --files-without-match, -q일치/미일치 파일 경로, 무출력지원
-m <N>, -A/-B/-C파일당 최대 개수 및 전후 문맥지원-- 구분선 포함
--passthru일치·비일치 줄 모두 출력지원--passthru/-A/-B/-C 중 마지막 옵션 우선
-n / -N줄 번호 표시 / 숨기기지원파이프 시에도 기본 ON
-H / -I, --column, --vimgrep파일명 제어, 열 번호, vimgrep지원
--json, -0, -r <TEXT>rg JSON Lines, NUL 구분, $1 치환지원
--color <WHEN>auto, always, ansi, never지원기본 auto는 TTY와 NO_COLOR/TERM=dumb 준수
--sort, --no-heading정렬, 헤더 끄기No-op항상 경로순 정렬; 헤더 사용 안 함

파일 순회 & Lancet 확장#

플래그의미상태비고
-g, --iglob, -t, -T, --type-list글롭 및 파일 타입 필터지원긍정 글롭은 ignore/hidden을 덮어씀
--type-add <SPEC>사용자 타입 정의 (name:glob / include:)지원-t, -T, --files, --type-list 반영
-u / -uu / -uuu, -., --no-ignore제한 해제 및 숨김·ignore 옵션지원
-L, --max-depth, --max-filesize심볼릭 링크 추적, 깊이, 크기 (K/M/G)지원--trust-index -L은 라이브 순회로 폴백
--files, -j검색 대상 파일 나열, 스레드 수지원
--docsPDF·오피스·HWP·압축파일 인프로세스 검색확장기본 OFF(rg 호환 출력 유지)
--no-index, --trust-index, --index-dir.lancet 인덱스 동작 제어확장기본값은 항상 최신인 auto 모드
--pre <CMD>외부 전처리기미지원인프로세스 --docs로 대체
