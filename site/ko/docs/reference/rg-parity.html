lancet rg — ripgrep 기능 호환성 매트릭스

ripgrep 15.2와 바이트 단위로 대조 검증한 전체 플래그 호환성 매트릭스.

bench/rg_parity.py의 68개 엣지 케이스 픽스처(유니코드 케이스 폴딩, CRLF, 마지막 개행 누락, 바이너리 건너뛰기, -m+-C, --vimgrep, -L, --max-depth, --max-filesize)와 Linux v6.12 전체 쿼리를 ripgrep 15.2와 바이트 단위로 대조 검증했습니다.

패턴 & 매칭#

플래그의미상태비고
-e, --regexp <PATTERN>검색 패턴 (중복 지정 가능)지원정규식 선택(alternation)으로 결합
-f, --file <FILE>파일에서 줄당 하나씩 패턴 읽기 (- stdin)지원
-F, --fixed-strings리터럴 문자열로 취급지원
-i / -s / -S대소문자 무시 / 구분 / 스마트지원마지막 플래그 우선; AST 기반 -S(\W 무시 유지)
-w, --word-regexp단어 경계로 둘러싸인 매치만지원rg 경계 규칙과 동일(-w '@x' 지원)
-x, --line-regexp줄 전체에 걸친 매치만지원
-v, --invert-match매치하지 않는 줄 출력지원
-U, --multiline-dotall멀티라인 및 .에 \n 허용지원
-P, --pcre2전후방 탐색 및 역참조미지원선형 시간 Rust regex + 건전한 HIR 트라이그램 컴파일

출력 & 형식#

플래그의미상태비고
-o, -c, --count-matches매치 부분만 / 줄 수 / 총 매치 수지원
-l, --files-without-match, -q일치 경로 / 미일치 경로 / 무출력지원
-m <N>, -A, -B, -C파일당 최대 개수 및 전후 문맥지원후속 문맥도 -m 준수; -- 구분선 출력
--passthru (별칭 --passthrough)일치·비일치 줄 모두 출력지원비일치 파일도 출력; --passthru/-A/-B/-C 중 마지막 우선
-n / -N줄 번호 표시 / 숨기기지원파이프 시에도 기본 ON
-H / -I, --column, --vimgrep파일명 표시, 1-based 열, vimgrep지원-H/-I 중 마지막 우선
--json, -0, -r <TEXT>rg JSON Lines, NUL 구분, $1/${{name}} 치환지원
--color <WHEN>auto, always, ansi, never지원기본 auto는 TTY와 NO_COLOR/TERM=dumb 준수
--sort, --no-heading정렬, 파일명 헤더 끄기No-op항상 경로순 정렬; 헤더 사용 안 함

파일 순회, 필터링 & Lancet 확장#

플래그의미상태비고
-g, --iglob, -t, -T, --type-list글롭 및 타입 필터지원긍정 글롭은 ignore/hidden 덮어씀
--type-add <SPEC>NAME:GLOB 또는 NAME:include:A,B지원-t, -T, --files, --type-list 반영
-a, -u/-uu/-uuu, -., --no-ignore바이너리/숨김/무시 해제지원
-L, --max-depth, --max-filesize심볼릭 링크 추적, 깊이, 크기 (K/M/G)지원--trust-index -L은 라이브 순회로 폴백
--files, -j/--threads검색 대상 파일 출력, 워커 수지원
--docsPDF/오피스/HWP/압축파일 인프로세스 검색확장rg 호환성 유지를 위해 기본 OFF
--no-index, --trust-index, --index-dir.lancet 인덱스 동작 지정확장기본은 항상 최신인 auto 모드
--pre <CMD>파일별 외부 전처리기미지원인프로세스 --docs로 대체
