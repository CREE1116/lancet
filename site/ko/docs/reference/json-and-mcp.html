JSON 출력 스키마, MCP 11개 도구 명세 & 문제 해결

기계 판독용 JSON 스키마, MCP 도구 인벤토리, 거절·오류별 즉시 복구 절차.

--json 플래그나 lancet mcp로 호출하면 모든 명령이 Rust 구조체에서 직접 직렬화된 일관된 snake_case JSON을 반환합니다.

공통 Status & Error 규격#

모든 JSON 응답에는 status 필드(필요 시 error: {"message": string, "pos"?: number})가 포함됩니다:

  • "complete" (종료 0) — 검색 완료 또는 편집·패치 적용/검증 완료.
  • "empty" (종료 1) — 오류 없이 결과 0건.
  • "invalid_query" (종료 2) — 잘못된 LQL, 잘못된 줄 범위, 중복된 --find 등.
  • "unsupported" (종료 2) — 미지원 언어, 읽기 전용 문서 수정 시도, 거절된 rename 위치.
  • "conflict" (종료 2) — --rev가 현재 디스크 상태와 달라 OS 파일 잠금 하에 0바이트만 쓰고 중단됨.

MCP 11개 도구 상세 (lancet mcp)#

지원 프로토콜 버전: 2025-03-26, 2024-11-05. MCP에서는 status: "empty"도 정상(isError: false)이며, lancet_rg는 max_output_bytes(기본 128 KiB, 최대 4 MiB) 기준으로 줄 경계에서 깔끔히 잘립니다.

MCP 도구역할주요 인자 및 동작
lancet_fd파일·폴더 탐색pattern, path, dirs, tree, exts, type_classes, changed_within, index_mode
lancet_searchLQL 검색query, path, max_lines, max_cols, ocr, index_mode
lancet_rgripgrep 호환 검색pattern, paths, docs, passthru, type_add, max_output_bytes
lancet_outline선언·문서 뼈대path, max_depth, exts, limit, ocr
lancet_read정밀 범위·문서 읽기target, lines, symbol, page, sheet, rows, cols, entry, budget_tokens
lancet_refs어휘 AST 참조 & 랭킹symbol, path, rank, kinds, lang, limit
lancet_astAST 검색·치환pattern, path, lang, rewrite, apply (--read-only 시 차단)
lancet_edit잠금 CAS 편집--read-only 시 목록에서 제외; lines, symbol, find, edits, rev, apply
lancet_patch원자적 Diff 패치--read-only 시 목록에서 제외; patch, root, strip, apply, allow_syntax_errors
lancet_rename로컬 이름 변경--read-only 시 목록에서 제외; path, line, col?, old, new, rev?, apply?
lancet_index인덱스 관리action (status, sync, rebuild, compact); 변경 작업은 --read-only 시 차단

문제 해결 및 거절 사유별 복구법#

오류 / 거절원인정확한 복구 방법
status: "conflict" (종료 2)rev를 읽은 뒤 다른 작업이 파일을 수정함lancet read로 최신 내용과 새 rev를 다시 읽어 변경을 재계산해 적용합니다.
--find 거절 (비고유)찾을 문자열이 0회 또는 2회 이상 등장오류에 출력된 줄 번호를 확인하고 주변 문맥을 더 넓히거나 의도한 경우 --all을 추가합니다.
구문 오류 증가 거절편집·패치 후 Tree-sitter 구문 오류가 늘어남dry-run diff에서 괄호/따옴표 누락을 점검하고, 단계적 수정일 때만 --allow-syntax-errors를 씁니다.
lancet rename 거절전역/필드/Python 매개변수, 매크로·eval, 섀도잉오류 사유를 확인하고, 파일 간 심볼은 lancet refs + lancet edit --edits 또는 LSP를 씁니다.
ast --rewrite --apply + --limit일부만 잘라낸 치환은 실수로 적용할 수 없음--limit을 빼거나 --path 글롭으로 대상 파일을 좁힌 뒤 --apply하세요.
lancet rg -P 오류PCRE2 전후방 탐색·역참조 미지원룩어라운드 없는 Rust regex나 LQL before() / NOT으로 표현하세요.
lancet fd 경로 2개 오류fd는 [PATH] 인자를 최대 1개만 받음디렉터리마다 나눠 실행하거나 저장소 루트에서 -p/글롭 필터를 사용하세요.
