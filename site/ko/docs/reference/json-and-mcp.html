JSON 응답 스키마 & MCP 11개 도구 레퍼런스

Rust 구조체 기준 기계 판독용 JSON 응답 필드와 MCP 도구별 전체 파라미터 명세.

src/의 실제 Rust 직렬화 구조체와 src/mcp.rs에 정의된 MCP 11개 도구의 전체 파라미터 스키마입니다.

Status 열거형 & ErrorInfo#

  • Status: "complete" | "empty" | "invalid_query" | "unsupported" | "conflict"
  • ErrorInfo: {"message": string, "pos"?: number} (pos는 LQL 파싱 오류 시 설정)
