기존 도구(rg, fd, ast-grep, sed, patch, rga)에서 전환하기

ripgrep, fd, ast-grep의 익숙한 사용감을 그대로 가져오면서 통일된 좌표계와 무손실 편집을 더합니다.

이미 ripgrep, fd, ast-grep, sed, patch, rga에 익숙하다면 한 번에 다 바꿀 필요가 없습니다. Lancet은 기존 플래그를 그대로 받는 호환 진입점과 단계 간 이음새 오류를 없애는 안전장치를 함께 제공합니다.

ripgrep(rg)에서 오셨다면#

lancet rg는 ripgrep의 플래그, Rust regex 엔진, .gitignore / .ignore / .rgignore 규칙, 종료 코드(0 매치, 1 없음, 2 오류), 출력 형식을 그대로 구현했습니다(ripgrep 15.2와 바이트 단위 검증).

ripgrep 명령lancet 대안참고
rg foo srclancet rg foo src줄 번호가 기본 ON; 끄려면 -N
rg -i -w -t py toklancet rg -i -w -t py tok-i/-s/-S, -w, --type 규칙 동일
rg -g '*.toml' -C 2 patlancet rg -g '*.toml' -C 2 pat--passthru, --type-add, -L, --max-depth 지원
rg --files -t rslancet rg --files -t rs경로순으로 결정적 정렬 출력
rg -P '(?<=a)b'lancet 'before("a", "b", 1)' 또는 Rust regex-P / PCRE2는 의도적으로 미지원(선형 시간 + 건전한 트라이그램 컴파일 보장)
rg --pre pdftotext patlancet rg --docs pat외부 프로세스 없이 인프로세스로 PDF/오피스/HWP/압축 검색
lancet rg의 의도적 차이 3가지
  • 항상 경로순 정렬: rg --sort path와 동일하며 스레드 수와 무관하게 결정적입니다.
  • 줄 번호(-n) 기본 활성화: 파이프 출력에서도 켜져 있으며 -N으로 끕니다.
  • 파일명 헤더 없음: 항상 path:line:text 형식으로 출력하며 --color auto는 파이프 시 색상을 끕니다.

fd / find에서 오셨다면#

fd / findlancet fd차이점 및 확장 기능
fd -e rs -d 2 srclancet fd -e rs -d 2 src.lancet 인덱스가 있으면 바로 활용
fd -t d -d 2lancet fd --tree --dirs -d 2 .파일 없이 폴더 트리만 깔끔하게 출력
find . -mtime -7lancet fd --changed-within 7d단위: s, m, h, d, w
find . -name '*.pdf'lancet fd --type-class document내장 분류: code, document, spreadsheet, archive 등
fd pat dir1 dir2경로마다 호출하거나 LQL path: 사용lancet fd는 [PATH] 1개만 받음; 패턴이 경로처럼 보이면 -p pat 사용

ast-grep(sg)에서 오셨다면#

ast-greplancet ast중요한 차이
sg -p '$X.unwrap()' -l rslancet ast '$X.unwrap()' -l rs패턴에 리터럴이 있으면 .lancet 트라이그램 프리필터 가속
sg -p 'f($$$A)' -r 'g($$$A)' -Ulancet ast 'f($$$A)' -r 'g($$$A)' --apply기본은 dry-run diff; --apply일 때만 원자적 기록
sg -p 'if ($C) $S'lancet ast 'if ($C) $S'의미 차이: Lancet은 모양을 엄격히 매치함(if-else는 별개 구문 노드)
sg -l cpp ...lancet ast ... -l cppLancet --lang cpp는 .cpp/.cc 외에 .h 헤더도 함께 스캔

cat / sed / patch / rga에서 오셨다면#

기존 도구 사슬Lancet 대체해결된 실패 사례
sed -n '10,50p' f.rslancet read f.rs --lines 10:50XXH3-64 rev 반환 + --budget-tokens 상한 지원
하나의 rg 결과로 sed -i 2회lancet edit f.rs --edits - --rev REV --apply모든 hunk가 원본 줄 번호 기준; 심볼릭/하드 링크·권한 유지
patch -p1 < difflancet patch diff --apply모든 파일 사전 검증, 충돌 시 롤백(반쪽 패치 없음)
rga + pdftotext/pandoclancet 'pat' + lancet read f.pdf -p 2단일 추출 파이프라인으로 줄 번호 100% 일치

전문 도구를 그대로 써야 할 때#

적용 범위 경계
  • 버전 관리: git은 그대로 사용하세요. Lancet은 작업 트리를 검색하고(.gitignore 준수) git diff를 lancet patch로 안전하게 적용합니다.
  • 여러 파일에 걸친 타입 기반 리팩터링: 공개 API, 구조체 필드, 메서드 이름 일괄 변경은 LSP(rust-analyzer, tsserver, gopls)를 사용하세요. Lancet은 어휘 기반 refs와 단일 파일 스코프 증명 기반 lancet rename을 제공합니다.
