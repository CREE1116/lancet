아키텍처와 내부 구조

벤치마크 & 정직한 경쟁 도구 비교

실제 저장소에서 ripgrep, zoekt, ast-grep, tgrep, grix, aft, probe와 비교해 앞서는 점과 뒤지는 점을 모두 공개합니다.

Apple M4 Pro(arm64 macOS), 웜 캐시, hyperfine -N 5회 중앙값 기준입니다. auto, --trust-index, --no-index의 모든 텍스트 출력은 ripgrep 15.2와 바이트 단위로 대조했습니다.

정직한 요약: 우위와 열위#

양쪽 숫자를 가감 없이 확인하세요
  • Lancet이 앞서는 영역: 데몬 없는 20/20 0 ms 최신성; aft/tgrep 대비 1/3~1/7 인덱스 디스크 크기(Linux 141.8 MB vs 368.5 MB / 955.2 MB); grix 대비 약 1/3 피크 빌드 RAM(Linux 353.5 MB vs 1,001.6 MB); Django·Rust·Linux·LLVM 모두에서 가장 빠른 리터럴 AST 검색; 읽기·편집·패치·이름 변경까지 단일 바이너리 통합.
  • 상주 데몬이나 trust 전용 도구가 더 빠른 영역: 상주 데몬 tgrep serve는 Rust(119.2 ms vs 508.7 ms)·LLVM(19.9 ms vs 295.8 ms) regex with literal과 소형 리터럴 없는 정규식(Django 15.4 ms, Rust 60.9 ms)에서 데몬 없는 lancet auto보다 빠릅니다. grix --no-auto-index는 Linux 희귀 리터럴에서 lancet --trust-index보다 빠릅니다(11.5 ms vs 43.6 ms). 상주 aft(RAM 587~1,260 MB)는 Rust 희귀 리터럴(8.5 ms vs 73.5 ms)에서 앞섭니다. 리터럴 없는 정규식과 AST 패턴은 각각 rg(최대 1.4배 느림), ast-grep(0.6~1.0배) 수준입니다.
