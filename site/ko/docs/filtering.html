시작하기

무시 규칙, 글롭, 파일 타입 & 순회 경계

검색, fd, outline, refs, ast, index가 모두 공유하는 일관된 파일 필터링 및 순회 규칙.

Lancet은 lancet, rg, fd, outline, refs, ast, index 전역에서 ripgrep의 ignore 크레이트 순회 규칙을 동일하게 적용합니다.

무시 규칙 우선순위, 숨김 파일 & 바이너리#

  • 무시 파일 스택: .gitignore, Git exclude, .ignore, .rgignore를 준수합니다(--no-ignore 또는 -u로 해제).
  • 숨김 파일·폴더: .으로 시작하는 경로(.lancet 포함)는 기본 제외되며 --hidden / -.(lancet rg에선 -uu)로 포함합니다.
  • 바이너리 판별: 일반 텍스트 검색은 NUL 바이트가 있는 바이너리를 건너뜁니다(-a / --text / -uuu 또는 문서 어댑터 확장자 제외).
  • 긍정 글롭 우선: lancet rg에서 -g '*.lock' 같은 긍정 글롭은 ripgrep과 똑같이 ignore/hidden 설정을 덮어씁니다.

lancet rg 제한 해제 단계 (-u / -uu / -uuu)#

플래그동등 옵션동작
-u--no-ignoreignore 파일(빌드 산출물, node_modules 등)도 검색
-uu--no-ignore --hidden숨김 파일과 디렉터리도 검색
-uuu--no-ignore --hidden --text바이너리 파일까지 텍스트로 간주해 검색

글롭, 내장 파일 타입 & --type-add#

터미널
# 포함/제외 글롭 (!로 부정; 대소문자 무시 --iglob도 지원)
lancet rg -g 'src/**' -g '!src/generated/**' 'retry' .

# ripgrep 내장 파일 타입 포함/제외
lancet rg -t rust -T test 'unsafe' .

# 사용자 정의 타입 추가 또는 기존 타입 병합 (중복 지정 가능)
lancet rg --type-add 'web:*.{ts,tsx,css}' -t web 'ThemeProvider' .
lancet rg --type-add 'jvm:include:java,kotlin,scala' -t jvm 'Executor' .

# --type-add가 반영된 타입 목록 확인
lancet rg --type-add 'proto:*.proto' --type-list

LQL & fd 필터 (type:, ext:, path:, --type-class)#

LQL에서 같은 카테고리 내 여러 값은 OR로, 서로 다른 카테고리는 AND로 결합됩니다. src/walk.rs 규칙상 path: 값에 글롭 메타문자(*, ?, [, {)가 없으면 dir 자체와 dir/**를 모두 매치합니다.

터미널
# ext:(...) 내부는 OR, ext:와 path: 사이는 AND
lancet '"deadline" in ext:(rs,toml) path:crates/core'

# 의미 클래스로 최근 수정 문서 찾기
lancet fd --type-class document,spreadsheet --changed-within 14d

심볼릭 링크, 깊이 및 파일 크기 제한#

  • 심볼릭 링크 (-L / --follow): 기본 비활성. lancet rg -L --trust-index에서는 .lancet에 빠진 링크 대상까지 놓치지 않도록 의도적으로 라이브 순회로 폴백합니다.
  • 깊이·크기 상한: --max-depth N(1은 직계 자식만)과 --max-filesize NUM[K|M|G](rg), --min-size/--max-size(fd)가 라이브 순회와 --trust-index 양쪽에서 모두 적용됩니다.
  • fd 단일 경로 규칙: lancet fd [PATTERN] [PATH]는 최대 하나의 PATH만 받으며, 패턴이 폴더명과 같으면 -p PATTERN으로 명시하세요.
