시작하기

Lancet 공식 문서 — 설치 · 빠른 시작 · 치트시트

탐색, 트라이그램 인덱스 검색, 24개 언어 AST 치환, 정밀 읽기, CAS 편집을 하나의 Rust 바이너리로 통합합니다.

Lancet은 rg + fd + ast-grep + cat + sed + patch + pdftotext를 이어 쓰던 작업을 의존성 없는 단일 Rust 바이너리로 통합합니다. 모든 명령이 같은 .lancet 트라이그램 인덱스, 파일 필터 규칙, 1부터 시작하는 줄 번호, XXH3-64 rev 해시를 공유합니다.

한 줄로 요약한 설계 원칙

트라이그램 인덱스는 열지 않을 파일만 걸러냅니다. 후보 파일과 수정된 파일은 풀스캔과 완전히 동일한 평가기로 검증되며, 모든 쓰기는 배타적 잠금 기반 compare-and-swap으로 처리됩니다.

60초 전체 흐름 따라하기#

.lancet 인덱스는 선택 사항입니다. 인덱스가 없어도 모든 명령이 동작하며, 기본 auto 모드는 매 쿼리마다 디스크 메타데이터를 확인해 수정된 파일을 놓치지 않습니다.

터미널
# 1. 선택: 로컬 트라이그램 인덱스 한 번 빌드
lancet index .

# 2. 폴더 구조 파악 후 참조 수 순위로 핵심 심볼 찾기
lancet fd --tree --dirs -d 2 .
lancet refs --rank '*Service' --kind class src --limit 8

# 3. ripgrep 플래그 또는 LQL 논리·근접 쿼리로 검색
lancet rg -w execute_one src
lancet 'near("gradient", "clip", 30) in function | expand parent'

# 4. 필요한 심볼이나 줄 범위만 읽고 XXH3-64 `rev` 확보
lancet read src/search.rs --symbol execute_one --json

# 5. dry-run diff 확인 후 --rev, --apply로 원자적 반영
lancet edit src/search.rs --find 'let limit = 20;' \
  --with 'let limit = 50;' --rev <REV> --apply
