시작하기

Lancet 공식 문서 — 소개 · 설치 · 치트시트

하나의 좌표계 위에서, 인덱스로 훨씬 빠르게 코드와 문서를 찾고 읽고 고칩니다.

Lancet은 파일 탐색(fd), 트라이그램 인덱스 기반 검색(rg / LQL), 24개 언어 구조적 AST 검색·치환(ast), 범위·문서 정밀 열람(read / outline), compare-and-swap 편집(edit / patch / rename), 내장 stdio MCP 서버(mcp)를 바이너리 하나에 담은 Rust 도구입니다.

시작 전 핵심 규칙 하나

모든 검색 결과, AST 매치, 읽기 조각, 편집 구간이 1부터 시작하는 동일한 줄 번호와 XXH3-64 rev 해시를 공유합니다. PDF, 오피스, HWP/HWPX, 압축 파일 내부조차 검색과 read가 같은 줄 번호를 씁니다.

설치#

macOS, Linux(glibc 및 정적 musl), Windows용 사전 빌드 바이너리를 제공합니다. Rust 툴체인 없이 바로 설치할 수 있습니다.

macOS / Linux (Homebrew)
brew tap CREE1116/lancet https://github.com/CREE1116/lancet
brew install CREE1116/lancet/lancet
macOS / Linux (릴리스 설치 스크립트)
curl -fsSL https://raw.githubusercontent.com/CREE1116/lancet/main/install.sh | sh
Windows (PowerShell)
irm https://raw.githubusercontent.com/CREE1116/lancet/main/install.ps1 | iex
소스 빌드 (Cargo)
# 전체 바이너리 (~40 MB, Tree-sitter 24개 언어 + PDF/오피스/HWP 어댑터)
cargo binstall --git https://github.com/CREE1116/lancet lancet

# 텍스트·코드 전용 경량 바이너리 (~4 MB, 문서 어댑터 제외)
cargo install --git https://github.com/CREE1116/lancet --no-default-features

60초 빠른 시작#

.lancet 인덱스는 선택 사항입니다. 인덱스가 없어도 동일하게 동작하며, 기본 auto 모드는 매 쿼리마다 파일 변경 여부를 확인합니다.

터미널
# 1. 선택: 로컬 트라이그램 인덱스 한 번 빌드
lancet index .

# 2. 폴더 구조 먼저 확인 후 참조 빈도순 핵심 심볼 찾기
lancet fd --tree --dirs -d 2 .
lancet refs --rank '*Service' --kind class src --limit 8

# 3. ripgrep 문법 또는 LQL 논리·근접 쿼리로 검색
lancet rg -w execute_one src
lancet 'near("gradient", "clip", 30) in function | expand parent'

# 4. 필요한 함수/범위만 읽고 `rev` 확보
lancet read src/search.rs --symbol execute_one --json

# 5. dry-run diff 확인 후 --rev와 --apply로 원자적 반영
lancet edit src/search.rs --find 'let limit = 20;' --with 'let limit = 50;' --rev <REV> --apply

문서 둘러보기#

시작하기기존 도구에서 전환하기rg, fd, ast-grep, sed, patch, rga 사용자가 바로 옮겨 탈 수 있는 대조표와 의도적 차이점.실전 가이드낯선 코드베이스 탐색fd --dirs, refs --rank, outline, batch, budget-tokens 페이지네이션으로 토큰 절약하기.실전 가이드안전한 편집·패치·로컬 이름 변경--edits로 줄 밀림 방지, --rev 동시성 제어, 다중 파일 patch 및 로컬 스코프 rename.레퍼런스CLI·LQL·JSON/MCP 전체 명세전체 플래그, LQL EBNF 문법, 24개 AST 언어, MCP 11개 도구 및 오류 복구표.
