AI 에이전트 연동: 내장 MCP 서버 & 공식 스킬

줄바꿈 구분 stdio JSON-RPC 서버로 11개 도구를 연결하거나 공식 스킬을 두 줄로 설치하세요.

AI 코딩 에이전트는 셸 CLI로 직접 쓰거나, 의존성 없는 내장 Model Context Protocol (MCP) stdio 서버와 skills/lancet/ 공식 스킬 패키지로 연동해 쓸 수 있습니다.

내장 MCP 서버 실행 (lancet mcp)#

lancet mcp는 stdin/stdout 위에서 줄바꿈 구분 JSON-RPC 2.0(MCP 버전 2025-03-26 / 2024-11-05)을 구사하며, 별도 데몬 없이 Lancet의 Rust 엔진을 인프로세스로 즉시 호출합니다.

플래그기본값동작
--root <DIR>.도구 호출의 상대 경로 해석 기준 디렉터리 (chroot/샌드박스가 아님; CLI처럼 절대 경로나 ..도 허용됨)
--read-onlyfalsetools/list에서 lancet_edit, lancet_patch, lancet_rename을 숨기고 쓰기(lancet_ast apply, 인덱스 변경)를 거부
--trust-indexfalse개별 호출에서 덮어쓰지 않는 한 기본 index_mode를 trust로 설정
-j, --threads <NUM>CPU 코어 수Rayon 워커 스레드 수

클라이언트별 설정 예시#

복사해서 바로 쓸 수 있는 JSON 템플릿은 skills/lancet/references/mcp-config.json에도 있습니다.

Claude Code#

터미널
# 기본 읽기·쓰기 모드
claude mcp add --transport stdio lancet -- lancet mcp --root .

# 읽기 전용 탐색 모드
claude mcp add --transport stdio lancet -- lancet mcp --root . --read-only

Cursor (.cursor/mcp.json 또는 ~/.cursor/mcp.json)#

JSON
{
  "mcpServers": {
    "lancet": {
      "command": "lancet",
      "args": ["mcp", "--root", "."]
    }
  }
}

Claude Desktop / Windsurf / Antigravity#

데스크톱 앱이 저장소 밖에서 실행되는 경우 절대 경로로 --root를 지정하세요.

JSON
{
  "mcpServers": {
    "lancet": {
      "command": "lancet",
      "args": ["mcp", "--root", "/abs/path/to/your/repo"]
    }
  }
}

OpenAI Codex (~/.codex/config.toml)#

TOML
[mcp_servers.lancet]
command = "lancet"
args = ["mcp", "--root", "."]

공식 에이전트 스킬 설치#

skills/lancet/ 패키지는 에이전트에게 LQL 문법, 24개 AST 언어 별칭, rev 기반 CAS 편집 흐름, 기존 도구 대비 선택 기준을 알려 줍니다.

터미널
# 프로젝트 로컬 (.agents 공통 규약)
mkdir -p .agents/skills && ln -s "$(pwd)/skills/lancet" .agents/skills/lancet

# Claude Code / Codex / Antigravity 개인 설정
mkdir -p ~/.claude/skills && cp -R skills/lancet ~/.claude/skills/lancet
mkdir -p ~/.codex/skills  && cp -R skills/lancet ~/.codex/skills/lancet
mkdir -p ~/.gemini/config/skills && cp -R skills/lancet ~/.gemini/config/skills/lancet

11개 도구 & 내장 프롬프트 2종#

모든 조회·검색 도구는 결과 0건을 정상적인 empty(isError: false)로 처리하며, 쓰기 도구는 기본값이 apply: false(dry-run unified diff)입니다. 전체 파라미터와 스키마는 JSON · MCP 명세를 참고하세요.

  • 탐색·검색: lancet_fd, lancet_outline, lancet_search, lancet_rg, lancet_refs(rank: true 포함), lancet_ast, lancet_read.
  • 안전한 수정: lancet_edit, lancet_patch, lancet_rename, 그리고 apply: true를 준 lancet_ast.
  • 인덱스 관리: lancet_index(status, sync, rebuild, compact).
  • 내장 프롬프트: prompts/list의 lancet-explore, lancet-safe-edit.
