Integrating AI Agents: MCP Server & Official Skill

Expose all 11 engines over newline-delimited stdio JSON-RPC or install the cross-agent Skill in two commands.

AI coding agents can invoke Lancet either through shell commands or natively through its zero-dependency stdio Model Context Protocol (MCP) server — paired with the cross-agent Official Skill in skills/lancet/.

Starting the Built-in MCP Server (lancet mcp)#

lancet mcp speaks newline-delimited JSON-RPC 2.0 over stdin/stdout (supporting MCP revisions 2025-03-26 and 2024-11-05) and executes Lancet's Rust engines directly in-process without async daemon overhead.

FlagDefaultBehavior
--root <DIR>.Default working directory for resolving relative paths in tool calls (not a chroot/sandbox; absolute or .. paths work like the CLI)
--read-onlyfalseOmits lancet_edit, lancet_patch, and lancet_rename from tools/list and refuses writes (lancet_ast apply, mutating lancet_index actions)
--trust-indexfalseSets default index_mode to trust instead of auto unless overridden per tool call
-j, --threads <NUM>CPU countRayon worker thread count

Client Configurations#

Ready-to-copy templates are also shipped in skills/lancet/references/mcp-config.json.

Claude Code#

Terminal
# Standard read/write server
claude mcp add --transport stdio lancet -- lancet mcp --root .

# Read-only exploration mode
claude mcp add --transport stdio lancet -- lancet mcp --root . --read-only

Cursor (.cursor/mcp.json or ~/.cursor/mcp.json)#

JSON
{
  "mcpServers": {
    "lancet": {
      "command": "lancet",
      "args": ["mcp", "--root", "."]
    }
  }
}

Claude Desktop / Windsurf / Antigravity#

Pass an absolute --root path when the desktop host launches outside your project directory:

JSON
{
  "mcpServers": {
    "lancet": {
      "command": "lancet",
      "args": ["mcp", "--root", "/abs/path/to/your/repo"]
    }
  }
}

OpenAI Codex (~/.codex/config.toml)#

TOML
[mcp_servers.lancet]
command = "lancet"
args = ["mcp", "--root", "."]

Installing the Official Agent Skill#

The cross-agent Skill package (skills/lancet/) teaches agents LQL syntax, all 24 AST language aliases, compare-and-swap rev workflows, and when to prefer lancet over legacy tools.

Terminal
# Project-local (.agents universal convention)
mkdir -p .agents/skills && ln -s "$(pwd)/skills/lancet" .agents/skills/lancet

# Claude Code / Codex / Antigravity personal skills
mkdir -p ~/.claude/skills && cp -R skills/lancet ~/.claude/skills/lancet
mkdir -p ~/.codex/skills  && cp -R skills/lancet ~/.codex/skills/lancet
mkdir -p ~/.gemini/config/skills && cp -R skills/lancet ~/.gemini/config/skills/lancet

11 Tools & 2 Built-in Prompts#

Every read/search tool treats 0 matches as a normal empty result (isError: false). Write operations default to apply: false (dry-run unified diff). See the full parameter and response schema tables in JSON & MCP Reference.

  • Exploration & search: lancet_fd, lancet_outline, lancet_search, lancet_rg, lancet_refs (including rank: true), lancet_ast, lancet_read.
  • Safe mutations: lancet_edit, lancet_patch, lancet_rename, plus lancet_ast with apply: true.
  • Index control: lancet_index (status, sync, rebuild, compact).
  • Built-in prompts: lancet-explore and lancet-safe-edit via prompts/list.
Minimal AGENTS.md / CLAUDE.md snippet
Prefer lancet (lancet_* MCP tools or lancet CLI) over rg/fd/ast-grep/cat/sed for discovery, search, bounded reads, and CAS edits (read --rev -> edit --apply).
