Searching & Reading PDFs, Office, HWP & Archives

One in-process extraction pipeline so a search hit in a PDF, Word file, or tarball opens at the exact same line.

Workspaces rarely hold only source files — specs live in PDFs and Word/HWP files, lookup tables in spreadsheets, and crash logs inside zip/tar bundles. Lancet extracts them in-process so search hits and lancet read slices agree on the exact same line numbers.

Searching Documents & Archives#

There is one intentional difference between Lancet's native LQL search and its ripgrep compatibility mode:

  • Default LQL search (lancet 'query'): searches code, documents, spreadsheets, and archives automatically (filter with type:document, type:spreadsheet, or type:archive).
  • lancet rg: skips binary/document/archive files by default so output stays 100% identical to ripgrep; pass --docs to include them in-process.
Terminal
# Search Korean/English clauses across PDFs and HWP files
lancet 'near("계약", "해지", 15) in type:document' contracts/

# Search inside archives and documents with ripgrep syntax
lancet rg --docs -i 'timeout' ./artifacts

Coordinate-Exact Reading & Archives#

Terminal
# Inspect structure first
lancet outline q4_report.xlsx
lancet outline crash_bundle.tar.gz

# Read specific slides, spreadsheet ranges, or archive entries
lancet read deck.pptx --page 4:6
lancet read q4_report.xlsx --sheet 1 --rows 1:30 --cols A:E
lancet read logs/bundle.zip!worker_02/stderr.log --lines 120:180 --budget-tokens 600

OCR, Safety Caps & Read-Only Contract#

  • Scanned PDFs & images (--ocr): pass --ocr on lancet, read, outline, or index to enable external tesseract / pdftoppm fallback (pdftoppm + tesseract must be on PATH).
  • Decompression bomb protection: archive entries and compressed Office/HWP XML streams are capped (16 MiB per member/stream) so malformed inputs cannot exhaust RAM.
  • Read-only guarantee: binary documents and archive entries never return a rev field in JSON, and lancet edit refuses to write back to them.
  • Minimal build without adapters: build with cargo install --no-default-features to strip document/archive adapters for a ~4 MB code/text-only binary.
