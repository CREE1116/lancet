Exploring Unfamiliar Codebases with Low Context

Orient cleanly in five calls instead of burning context tokens on blind whole-file reads.

The fastest way for a developer or AI agent to burn context tokens and stall is to read whole files blindly. Lancet supports a 5-step funnel that narrows thousands of files down to the exact lines you need.

1. Map Folders Without File Noise#

Start with directory structure before listing files or running searches:

Terminal
lancet fd --tree --dirs --max-depth 2 .
lancet fd --changed-within 2d -t f src

Adding --dirs (equivalent to -t d) renders only folders under --tree, giving an architectural map in a couple dozen lines.

2. Rank Core Declarations with refs --rank#

When entering an unfamiliar repository, find which classes, structs, interfaces, or functions are actually central by ranking them by lexical reference count:

Terminal
# Top 10 most-referenced Service classes
lancet refs --rank '*Service' --kind class src --limit 10

# Top referenced functions across a directory
lancet refs --rank '*' --kind function --limit 10 src

# Inspect definitions & call sites (excluding comments and strings)
lancet refs SearchOptions src --lang rs --json
Understanding shared names in --rank

Lancet uses the trigram index (for globs with a literal run like Service) and parses declarations across AST grammars. If an entry shows (name shared by N declarations) or definitions > 1 in JSON, multiple declarations share that identifier lexically.

3. Read Skeletons Before Bodies (outline)#

Use lancet outline to inspect declaration signatures, Markdown heading trees, Excel/ODS sheet names, or archive entries with exact line bounds:

Terminal
lancet outline src/search.rs
lancet outline docs/architecture.md
lancet outline financial_model.xlsx
lancet outline logs/bundle.zip

4. Batch Multiple Searches & Refine with Pipes#

If an agent needs answers to several related questions, lancet batch opens the index and walks the tree once for all of them. Combine with LQL pipe stages to compact output:

Terminal
# One shared index open + tree walk for 3 queries
lancet batch src \
  -q 'near("retry", "backoff", 20) in function' \
  -q '"Conflict" in ext:rs' \
  -q 'fuzzy("idempotent", 1) | files'

# Discover top co-occurring terms and enforce a token cap
lancet '"trigram" in ext:rs | terms top:10 | budget tokens:1200' src

5. Paginate Reads by Token Budget#

Read only the target symbol (including doc comments and attributes) or a slice bounded by --budget-tokens. When truncated, continue from next_line:

Terminal
lancet read src/search.rs --symbol execute_one
lancet read src/search.rs --lines 100:400 --budget-tokens 800 --json
Measured context savings

In the why-one-tool suite, targeting lines/symbols/budgets used 5–30× less context than reading whole files while preserving the exact line numbers and rev token needed for safe editing.
