Lancet Documentation — Introduction & Cheat Sheet

Find, read, and change code and documents on one coordinate system, at index speed.

Lancet is a single Rust binary that unifies discovery (fd), trigram-indexed search (rg / LQL), structural AST search & rewrite (ast), exact range/document reading (read / outline), compare-and-swap editing (edit / patch / rename), and an embedded stdio MCP server (mcp).

One rule before you start

Every search hit, AST match, read slice, and edit hunk agrees on exact 1-based line numbers and XXH3-64 rev hashes. Even PDFs, Office files, HWP/HWPX, and archive entries share the exact same line numbering between search and read.

Installation#

Install a prebuilt binary on macOS, Linux (glibc and static musl), or Windows — no Rust toolchain needed:

macOS / Linux (Homebrew)
brew tap CREE1116/lancet https://github.com/CREE1116/lancet
brew install CREE1116/lancet/lancet
macOS / Linux (Release Installer)
curl -fsSL https://raw.githubusercontent.com/CREE1116/lancet/main/install.sh | sh
Windows (PowerShell)
irm https://raw.githubusercontent.com/CREE1116/lancet/main/install.ps1 | iex
From source (Cargo)
# Full binary (~40 MB, 24 Tree-sitter grammars + PDF/Office/HWP adapters)
cargo binstall --git https://github.com/CREE1116/lancet lancet

# Lean text/code-only binary (~4 MB, no document adapters)
cargo install --git https://github.com/CREE1116/lancet --no-default-features

60-Second Walkthrough#

Run this loop in any repository. Building .lancet is optional — commands work identically with or without an index, and auto mode checks disk freshness on every query.

Terminal
# 1. Optional: build the local trigram index once
lancet index .

# 2. Map folders first, then rank core symbols by lexical usage
lancet fd --tree --dirs -d 2 .
lancet refs --rank '*Service' --kind class src --limit 8

# 3. Search with ripgrep syntax or LQL boolean/proximity queries
lancet rg -w execute_one src
lancet 'near("gradient", "clip", 30) in function | expand parent'

# 4. Read exact lines or symbols and capture `rev`
lancet read src/search.rs --symbol execute_one --json

# 5. Preview a dry-run diff, then commit atomically with --rev and --apply
lancet edit src/search.rs --find 'let limit = 20;' --with 'let limit = 50;' --rev <REV> --apply
