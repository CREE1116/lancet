Getting Started

Coming from rg, fd, ast-grep, sed, patch & rga

Keep the mental models you already know from ripgrep, fd, and ast-grep — with unified coordinates and zero-loss editing.

If you already use ripgrep, fd, ast-grep, sed, patch, or rga, you do not have to relearn everything at once. Lancet provides direct drop-in entrypoints alongside tighter guarantees across steps.

Coming from ripgrep (rg)#

lancet rg shares ripgrep's flag names, Rust regex engine, .gitignore / .ignore / .rgignore rules, exit codes (0 hit, 1 miss, 2 error), and output formats — tested byte-for-byte against ripgrep 15.2.

ripgrep Commandlancet EquivalentNotes
rg foo srclancet rg foo srcLine numbers on by default; pass -N to hide
rg -i -w -t py toklancet rg -i -w -t py tokIdentical -i/-s/-S, -w, and --type rules
rg -g '*.toml' -C 2 patlancet rg -g '*.toml' -C 2 patSupports --passthru, --type-add, -L, --max-depth
rg --files -t rslancet rg --files -t rsDeterministic path-sorted list
rg -P '(?<=a)b'lancet 'before("a", "b", 1)' or Rust regex-P / PCRE2 intentionally omitted (linear-time + sound trigram lowering)
rg --pre pdftotext patlancet rg --docs patIn-process PDF/Office/HWP/archive extraction without spawning subprocesses
Intentional differences in lancet rg
  • Always path-sorted: equivalent to rg --sort path (deterministic across threads).
  • -n enabled by default: stays on even when stdout is piped; use -N to disable.
  • No grouped headings: always prints path:line:text, with --color auto disabled when piped.

When NOT to Replace Specialized Tools#

Scope boundaries
  • Version control: keep using git; Lancet searches working trees (respecting .gitignore) and consumes git diff via lancet patch.
  • Cross-file type-checked refactoring: keep your LSP (rust-analyzer, tsserver, gopls) when renaming public APIs, struct fields, or traits across files. Lancet provides lexical refs plus single-file scope-proven lancet rename.
