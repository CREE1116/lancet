Lancet Query Language (LQL v0.1) & 24-Language AST Spec

Formal EBNF grammar, matcher/scope semantics, 24 --lang aliases, and AST metavariable rules.

Lancet Query Language (LQL v0.1) compiles to a deterministic IR evaluated identically on indexed candidates and full scans. Unknown operators, filters, or trailing tokens never fail silently — they return status: "invalid_query" with an exact byte offset.

LQL v0.1 Formal Grammar#

EBNF
query   := ["find"] expr ("in" scope)* ("|" stage)*
expr    := or_expr
or_expr := and_expr ("OR" and_expr)*
and_expr:= unary (("AND")? unary)*          # adjacent terms form implicit AND
unary   := "NOT" unary | primary
primary := string
         | word                            # unquoted single token -> literal
         | "(" expr ")"
         | "regex(" string ")"
         | "fuzzy(" string ["," uint] ")"  # k in 0..=3, default 1
         | "symbol(" string ")" | "symbol:" (string | word)
         | "near(" matcher "," matcher "," uint ")"
         | "before(" matcher "," matcher "," uint ")"

matcher := string | word | "regex(" string ")" | "fuzzy(" string ["," uint] ")"
         | "symbol(" string ")" | "symbol:" (string | word)

scope   := ("line" | "block" | "file" | "function"
         |  "type:" values | "ext:" values | "path:" values)+
values  := value | "(" value ("," value)* ")"

stage   := "limit" uint                    # uint >= 1
         | "count"
         | "files"
         | "group" "file"
         | "expand" ("parent" | "unit" | "context:" uint)
         | "sort" ("count" ["asc" | "desc"] | "path")
         | "terms" ["top:" uint]           # 1..=100, default 15
         | "budget" ["tokens:"] uint       # uint >= 1

Operator precedence is NOT > AND (explicit or implicit) > OR. Run lancet parse '<QUERY>' to view the normalized canonical query and JSON IR.

Matchers, Scopes & Pipe Stages#

ConstructExact Semantics
"text" / bare tokenCase-insensitive (Unicode simple case folding) substring match.
regex("pat")Rust regex multi-line mode (^/$ match line boundaries). Case-sensitive unless (?i) is set.
fuzzy("word", k)Word tokens within char-level Levenshtein distance 0 <= k <= 3 (default 1), accelerated by sound q-gram thresholds.
symbol("name") / symbol:nameExact (case-insensitive) Tree-sitter symbol definition match (.rs, .py, .js, .ts, .tsx, .go).
near(a, b, d) / before(a, b, d)Both match in unit with token distance |tok(b) - tok(a)| <= d (before requires b strictly after a).
in file / in block / in linefile (default), non-blank line runs (block), or single line (match [start, end) must lie inside the unit).
in functionTree-sitter function/method AST nodes (.rs, .py, .js, .ts, .tsx, .go); sets symbol on hits.
type: / ext: / path:Values inside a category OR; across categories AND. type: supports code, document, spreadsheet, config, log, data, archive, image, other.
| limit / files / count / group fileCompact projections and deterministic hit caps.
| expand / sort / terms / budgetExpand surrounding parent/context, sort by hit count/path, extract co-occurring tokens, or enforce estimated token cap.

Metavariable & Rewrite Semantics#

  • $VAR: matches a single named AST node; repeating the same name ($X == $X) enforces structural equality.
  • $_: anonymous single-node wildcard (not captured into template output).
  • $$$ARGS: zero or more sibling AST nodes (bounded by memoization and a per-node step budget against catastrophic backtracking).
  • Statement metavariables: C-like patterns such as if ($C) $S and { $$$B } work; note that if ($C) $S strictly matches if without else (unlike ast-grep).
  • Rewrite rules: --rewrite defaults to dry-run; --apply refuses --limit; nested overlapping matches in one file are skipped and counted in skipped_overlaps; --lang cpp includes .h headers as well as .cpp/.cc.
