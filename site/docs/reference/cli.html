Complete CLI & lancet rg Parity Reference

Exhaustive subcommand syntax, exit codes, and ripgrep 15.2 compatibility matrix.

Every subcommand shares global traversal semantics (.gitignore / .ignore / .rgignore), deterministic sorting, and structured exit codes.

Exit Codes#

CodeMeaningStatus Values
0Success / match foundcomplete
1No matches found (or missing index in status)empty
2Invalid query/flags, unsupported op, conflict, or I/O errorinvalid_query, unsupported, conflict

Patterns & Matching#

FlagMeaningStatusNotes
-e, --regexp <PAT>Search pattern (repeatable)SupportedCombined with alternation
-f, --file <FILE>Read patterns per line (- stdin)Supported
-F, --fixed-stringsTreat patterns as literalsSupported
-i / -s / -SIgnore-case / case-sensitive / smart-caseSupportedLast flag wins; AST-aware -S (e.g. \W stays insensitive)
-w / -x / -vWord / whole-line / invert matchSupportedMatches rg word-boundary rules
-U, --multiline-dotallMultiline match & . matches \nSupported
-P, --pcre2PCRE2 lookarounds & backrefsUnsupportedRust regex only for linear-time guarantee & sound trigram compilation
