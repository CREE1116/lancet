JSON Output Schemas, MCP 11-Tool Spec & Troubleshooting

Machine-readable schemas, MCP tool inventory, and concrete recovery recipes for every refusal.

When invoked with --json (or over lancet mcp), every command returns stable, snake_case JSON structs backed directly by Lancet's Rust types.

Shared Status & Error Envelope#

Every JSON response carries a status field (and optional error: {"message": string, "pos"?: number}):

  • "complete" (exit 0) — finished with results or applied/dry-run edit.
  • "empty" (exit 1) — finished cleanly with 0 hits.
  • "invalid_query" (exit 2) — malformed LQL, invalid range/flag, or non-unique --find.
  • "unsupported" (exit 2) — unsupported language, read-only document target, or disallowed rename site.
  • "conflict" (exit 2) — stale --rev or concurrent modification detected under OS file lock; 0 bytes written.

MCP 11-Tool Reference (lancet mcp)#

Protocol revisions supported: 2025-03-26, 2024-11-05. Under lancet mcp, status: "empty" still returns isError: false; lancet_rg output caps cleanly at line boundaries via max_output_bytes (default 128 KiB, hard cap 4 MiB).

MCP ToolRoleKey Parameters & Notes
lancet_fdFiles/dirs discoverypattern, path, dirs, tree, exts, type_classes, changed_within, index_mode
lancet_searchLQL queryquery, path, max_lines, max_cols, ocr, index_mode
lancet_rgripgrep searchpattern, paths, docs, passthru, type_add, max_output_bytes
lancet_outlineSkeletons & manifestspath, max_depth, exts, limit, ocr
lancet_readExact slices & docstarget, lines, symbol, page, sheet, rows, cols, entry, budget_tokens
lancet_refsLexical AST refs & ranksymbol, path, rank, kinds, lang, limit
lancet_astAST search & rewritepattern, path, lang, rewrite, apply (refused under --read-only)
lancet_editLocked CAS editOmitted under --read-only; supports lines, symbol, find, edits, rev, apply
lancet_patchAtomic unified diffOmitted under --read-only; patch, root, strip, apply, allow_syntax_errors
lancet_renameLocal binding renameOmitted under --read-only; path, line, col?, old, new, rev?, apply?
lancet_indexIndex managementaction (status, sync, rebuild, compact); mutating actions refused under --read-only

Troubleshooting & Refusal Recovery#

Error / RefusalCauseExact Recovery
status: "conflict" (exit 2)File changed on disk since rev was readRun lancet read again, recompute your edit against the new lines, and retry with the fresh rev.
--find refused (non-unique)Literal appeared 0 or >1 timesInspect line numbers printed in the error; expand surrounding context in --find or add --all if intentional.
Syntax error increase refusedEdit or patch increased Tree-sitter error countCheck the preview diff for missing braces/quotes; pass --allow-syntax-errors only if intentionally staging a partial fix.
lancet rename refusedTop-level/field/Python param, macro/eval, or shadowingCheck error message; for non-local/cross-file symbols use lancet refs + lancet edit --edits or your LSP.
ast --rewrite --apply with --limitPartial capped rewrites cannot be applied blindlyDrop --limit or narrow scope with --path globs before --apply.
lancet rg -P errorPCRE2 lookarounds/backreferences unsupportedUse Rust regex without lookarounds, or rewrite via LQL before() / NOT.
lancet fd usage error on 2 pathsfd accepts at most one [PATH] argumentInvoke once per directory or search from repo root with -p / glob filters.
