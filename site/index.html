Search · read · edit — for AI coding agents

Find, read and change code at index speed.

One Rust binary replaces the rg + fd + ast-grep + cat + sed chain. Every step shares one index and one coordinate system, results are always fresh, and edits from two agents never silently overwrite each other.

How it works

    
Three ideas, one binary.

    
The index only decides which files not to open. Search, read and edit agree on every line number. Every write is a compare-and-swap.

Features

    
Everything an agent does to a codebase.

    

      

        

        
Index speed, never stale

        
A trigram index picks candidate files; every candidate is checked by the same evaluator a full scan uses. Files edited since indexing are found by mtime/size/ctime/inode and scanned live. No daemon to run.

      

      

        

        
ripgrep, byte for byte

        
lancet rg takes ripgrep's flags and prints ripgrep's output, checked byte for byte on 8 codebases. It reads .gitignore, .rgignore, globs and --type the same way.

      

      

        

        
Structural search & rewrite

        
lancet ast '$X.unwrap()' --rewrite '$X?' in 24 Tree-sitter languages, with $$$ARGS and statement metavariables. A rewrite is a dry-run diff until --apply.

      

      

        

        
Exact reads, small context

        
read --symbol, line ranges, PDF pages and spreadsheet cells, all under a token budget. On the same lookups it used 5–30× less context than reading whole files.

      

      

        

        
Safe edits for many agents

        
edit, patch and AST rewrites write through one locked compare-and-swap. A stale --rev gets conflict and writes nothing. Symlinks, hard links and file mode are kept, and edits that add syntax errors are refused.

      

      

        

        
Documents in scope

        
PDF, DOCX, PPTX, XLSX, HWP, EPUB, ZIP and TAR are extracted in-process, with caps against decompression bombs. A hit on line 42 of a .docx is line 42 in read too.

Get started

    
Install, index once, hand it to your agent.

    

      

        
terminal


# optional: build the index once (it updates itself afterwards)
lancet index .

lancet fd --tree --max-depth 2 .
lancet rg -w spin_lock src
lancet read src/search.rs --symbol execute_one
lancet refs SearchOptions src
lancet ast '$X.unwrap()' src --lang rs --rewrite '$X?'
lancet edit src/net.rs --find 'retries = 3' \
  --with 'retries = 5' --rev <REV> --apply
git diff | lancet patch --apply

      

      

        

          
AGENTS.md / CLAUDE.md

          
        


# Paste into AGENTS.md / CLAUDE.md (full guide: docs/agent-instructions.md)

1. Orient:  lancet fd --tree --max-depth 2 . | lancet outline FILE
2. Search:  lancet rg -w SYMBOL src  |  lancet 'query in ext:rs'
3. Read:    lancet read FILE --symbol NAME --json   # note "rev"
4. Edit:    lancet edit FILE --find '...' --with '...' --rev REV --apply
5. On conflict (exit 2): read again, redo on new content, retry with new rev.
